# Security

This repository holds instructions for AI agents only: no code runs from it. The agent talks to the Prooflive.ai build API with a build link the user creates in their own account, which expires and can be revoked at any time from the site's Build with AI tab.

To report a security issue with this skill or with Prooflive.ai, email security@prooflive.ai. Please don't open a public issue for it.
